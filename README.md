# AI Chat

**本地 Ollama 对话客户端** —— 多轮对话、识图、联网搜索、会话管理，Windows 11 风格界面。

> 我的另一个项目 **AI-Downloader-for-Ollama** 是此项目的副产物。
> （本项目由 DeepSeek-V41-Flash 生成）

本程序**只负责对话，不含模型下载功能** —— 下载模型请用 AI Downloader，见下文。

---

## 如何下载模型（移步 AI Downloader）

**🔗 [https://github.com/a-j5611/AI-Downloader-for-Ollama](https://github.com/a-j5611/AI-Downloader-for-Ollama)**

AI Chat 本身**不提供下载**（模型页只有「使用 / 完全删除 / 清理未使用数据」）。
新模型请用配套的下载器获取，装好立刻能在 AI Chat 里看到。

### 步骤

1. 打开上面的仓库，下载 **Release** 里的压缩包（或克隆源码）；
2. 解压后双击 **`启动 AI Downloader.bat`**（项目**自带 Python 运行时**，无需安装环境）；
3. 在「AI 模型库」页搜索模型 → 右侧选择版本（**显示精确体积**）→ 点「下载」；
   * 下载前会弹窗，可自选 **1–32 线程** 与 **镜像源**（支持一键测速自动选最快）；
   * 支持**断点续传**、SHA-256 校验、停滞检测与「清理并重下」；
4. 下载完成后回到 **AI Chat** → 「模型」页会自动刷新出新模型 → 点「使用」即可开始对话。

也可以在「AI Downloader → 设置 → 下载位置（模型库）」把下载目录绑定到任意磁盘，
两个程序共用同一个 Ollama 目录（`OLLAMA_MODELS`），所以绑定后依然互相可见。

### 为什么分成两个程序

作者想要给他的项目推流（迫真）

## 功能

| 模块 | 说明 |
|---|---|
| **对话** | 流式输出、R1 思考过程折叠展开、多轮上下文、停止生成、每轮 token 速度统计、一键复制、**导出 Markdown** |
| **对话记录** | 左侧会话列表：**每次对话自动保存**、按首条提问自动生成标题；点击载入并完整还原思考过程与来源；支持新建 / 重命名 / 删除；重启后恢复上次会话 |
| **联网搜索** | 三态切换：关 / 快 / 深。**快**=单查询；**深**=问题自动拆成多组检索词 × 多引擎并发检索，合并去重后批量抓正文。**多引擎并发竞速**（实测单查询 1.4–1.6 秒）、结果缓存 10 分钟、每查询 10 条 |
| **搜索过滤** | **不检索字词释义**：词典/释义站点（汉典、百度汉语、有道、iciba、wiktionary、dictionary.com…）与"X是什么意思"类页面会被剔除；纯查词问题（非专业术语）**直接跳过联网**交给模型。**专业术语不受此限**（含拉丁字母/缩写或命中技术词表时照常检索） |
| **模型** | 列出本地模型（体积 / 量化 / 修改时间）、设为当前模型、**完全删除（含数据文件）**、**清理未使用数据**。**下载功能已移除**，需要新模型请用 AI Downloader（页面右上角有入口） |
| **识图** | 对话中附加图片（文件选择或 Ctrl+V 粘贴），自动缩放后交给视觉模型识别；当前模型不支持识图时会提示，并给出「去下载模型…」（跳转 AI Downloader）；图片随会话保存与还原 |
| **服务** | 状态灯实时监测、启动 / 停止 / 重启 Ollama、接口地址与版本、程序与模型目录、模型磁盘占用、进程内存与 CPU |
| **设置** | 主题 **跟随系统 / 浅色 / 深色**、**强调色（8 色 + 跟随 Windows）**、中文 / English、背景图片（模糊与压暗可调）、内置渐变、生成参数（温度 / top_p / 线程数 / 上下文 / 最大生成长度） |
| **日志** | 应用事件日志与服务端日志，可复制、可清空 |

## 界面：Windows 11 风格

* 配色与 WinUI 设计令牌一致：
  * 浅色 `#F3F3F3` 底 / `#FFFFFF` 卡片 / `#0067C0` 强调 / `#1A1A1A` 文字
  * 深色 `#202020` 底 / `#2B2B2B` 卡片 / `#60CDFF` 强调 / `#FFFFFF` 文字
* 卡片 8px 圆角 + 1px 描边；导航项为 Win11 设置页样式（圆角选中块 + 左侧强调条）
* 按钮 4~6px 圆角，边缘用「**密集圆弧 + 混色过渡环**」柔化，悬停 / 按下各有色阶
* 窗口通过 DWM 开启 Win11 圆角、深色标题栏，标题栏颜色跟随主题
* 字体统一 **微软雅黑**（含菜单、ttk 控件、对话框等 Tk 命名字体）
* 强调色：8 个 Win11 预设 + 「跟随 Windows」（读 DWM `ColorizationColor` 并吸附最近预设）

## 运行

双击 **`启动 AI Chat.bat`**（或直接双击 `AIChat.pyw`）。

启动器会依次尝试：项目内 `runtime\python\pythonw.exe` → 系统 `pythonw.exe`。
需要 Python 3.10+ 且带 tkinter；有 Pillow 才能用背景图与图片处理。

首次启动会自动把旧版 `DeepSeekController` 的配置与会话迁移到 `%APPDATA%\AIChat`。

## 目录结构

```
AIChat.pyw                 入口（无控制台，单实例）
启动 AI Chat.bat            启动器
app/
  main_window.py           窗口外壳、导航、背景、主题应用
  chat_view.py             对话：流式输出、思考过程、图片、Markdown 渲染、导出
  websearch.py             联网搜索：多引擎并发、结果合并去重、释义过滤、上下文拼装
  panels.py                模型 / 服务 / 设置 / 日志
  vision.py                识图相关对话框
  sessions.py              会话存取
  storage.py               模型删除与残留清理
  ollama_api.py            Ollama HTTP 客户端 + 服务管理
  gallery.py               （已移除：模型库下载窗口）
  widgets.py / theme.py / i18n.py / config.py / backgrounds.py
```

## 配置

`%APPDATA%\AIChat\config.json`：主题、强调色、语言、背景、模型目录、生成参数、
联网搜索（模式 / 每查询条数 / 抓正文页数 / 资料上限 / 是否过滤释义）。
会话：`%APPDATA%\AIChat\sessions\`；出错日志：`%APPDATA%\AIChat\error.log`。
